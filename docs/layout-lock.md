# 레이아웃 잠금

`pipeline/layout.py` 의 상수 50개를 `pipeline/layout.lock.json` 에 고정해 뒀다.
**bystander 편(2026-08-17 게시)을 만든 시점의 값이 기준**이다. 앞으로 나오는
영상이 이 화면 그대로 나오게 하는 것이 목적이다.

---

## 어떻게 지켜지나

```
python3 pipeline/layout_check.py            # 확인만. 다르면 exit 1
python3 pipeline/layout_check.py --update   # 의도적으로 바꿨을 때만 재잠금
```

`render.py` 가 렌더 시작 전에 이 검사를 부른다. 어긋나 있으면 프레임이 아예
만들어지지 않으므로, 규격이 틀어진 채로 영상이 나오는 일은 없다.

검사는 두 겹이다.

| 겹 | 무엇을 비교하나 | 무엇을 잡나 |
|---|---|---|
| 1 | `layout.py` **소스** ↔ `layout.lock.json` | 값을 고친 것 |
| 2 | 소스 ↔ 실제 `import layout` 결과 | **낡은 바이트코드** |

2번이 왜 필요한가 — macOS 시스템 파이썬(3.9)은 바이트코드를
`~/Library/Caches/com.apple.python/` 아래에 캐시한다. 무효화 기준이
(수정시각, 파일크기)라서 `0.745` → `0.760` 처럼 **길이가 같은 값을 같은 초에
고치면 낡은 `.pyc` 가 그대로 쓰인다.** 소스는 새 값인데 렌더는 옛 값으로
도는 상태가 되어, 눈으로는 절대 못 잡는다. 검사기가 이걸 감지하면 캐시를
지우고 "다시 실행하라"고 알린다.

## 바꾸고 싶을 때

레이아웃은 **바꾸지 않는 게 기본값**이다. 채널 정체성이 화면에서 나오고,
편마다 규격이 흔들리면 레퍼런스를 이식한 의미가 없어진다.

그래도 바꿔야 한다면:

1. `pipeline/layout.py` 수정
2. 시험 렌더로 눈으로 확인 (`render.py` 가 막으므로 먼저 3번을 해야 렌더된다)
3. `python3 pipeline/layout_check.py --update` 로 재잠금
4. **아래 변경 이력에 한 줄 남긴다** — 왜 바꿨는지가 없으면 다음에 되돌릴 수 없다

### 변경 이력

| 날짜 | 바꾼 값 | 이유 |
|---|---|---|
| 2026-08-17 | (최초 잠금) | bystander 편 기준으로 50개 상수 고정 |
| 2026-08-17 | `TITLE_TOP` 0.092→0.127<br>`TITLE_MID` 0.155→0.190<br>`TITLE_BOT` 0.234→0.269 | 타이틀과 이미지 사이 검정 여백 78px 이 비어 보였다. 타이틀 블록을 통째로 3.5%p 내려 이미지에 붙이고, 남는 여백은 위쪽(쇼츠 상단 UI 자리)으로 몰았다. 이미지와의 간격은 11px 만 남긴다 |
| 2026-08-17 | `SHOW_EMBLEM` 신설 = `false` | 하단 프로필 원 + 채널명 제거. 유튜브가 바로 아래 같은 정보(@ssulltissue + 구독)를 이미 띄워 중복이고 화면만 복잡했다. 채널 표기는 이미지 안 워터마크가 맡는다. `true` 로 되돌리면 예전 화면 그대로 나온다 (`PROFILE_Y`·`CHANNEL_Y` 값은 남겨 뒀다) |
| 2026-08-19 | `SPEED` 1.4→**1.0** | 나레이션이 1.4배속에서 8.5자/초로 너무 빨라 알아듣기 어려웠다(앵커 5~6, 빠른 유튜브 나레이션 7자/초). 전역 배속을 없애고 **문장 역할별 완급**을 `pipeline/audio.py` 로 옮겼다 — 훅 1.12 / 명칭공개 0.95 / 수치 1.18 / 반전 1.10 / 본문 1.34배속. 결과 6.4~6.8자/초. `SPEED` 를 다시 1.4로 올리면 완급 위에 이중으로 걸려 두 배로 빨라진다 |
| 2026-08-19 | `SPEED` 1.0→**1.4** (되돌림) | 역할별 완급(6.5자/초)이 "스피드가 너무 별로"라는 판단이라 원래 속도로 복구. `audio.py` 의 `PACING=False` 로 완급을 끄고 문장 간격도 0.03초로 되돌렸다. **음량 마감(EQ·컴프·-14 LUFS)은 유지** — 속도와 무관하고 "잘 안 들린다"를 해결한 부분이다 |

**이 값이 앞으로 만드는 모든 편의 기준이다.** `layout.lock.json` 이 51개 상수로
재잠금돼 있고 `render.py` 가 렌더 전에 대조하므로, 다른 규격으로는 프레임이 만들어지지 않는다.
