## 1. 프로필 사진 — ✅ 적용 완료 (2026-08-17)

파일: `assets/profile.png` (800×800)

**두루마리 휴지 마스코트.** 채널명이 "썰푸는휴지"라 얼굴 대신 휴지를 얼굴로 쓴다.
배경은 캐릭터와 같은 브랜드 노랑 `#FDD168`, 눈·튜브·반짝이에 캐릭터 머리색 계열
보라를 넣어 캐릭터와 한 세트로 읽히게 했다.

유튜브는 프로필을 **원형으로 마스킹**한다. 생성 원본은 휴지 자락이 원 밖으로
나가서, 콘텐츠 바운딩 원의 반지름을 **352px(원 반지름 400의 88%)** 로 줄여
가운데 정렬했다. 원형 미리보기는 `codex-images/_preview-profile-circle.png`.

원본(반짝이 포함 정사각)은 `codex-images/tissue-profile-01.png`,
배경을 딴 투명본은 `assets/tissue.png` — 배너가 이걸 쓴다.

**적용 경로**
`YouTube Studio → 맞춤설정 → 브랜딩 → 사진 → 업로드`
(권장 98×98 이상, 4MB 이하, PNG/GIF 가능 — 현재 파일은 조건 충족)

## 1-2. 채널 배너 — ✅ 적용 완료 (2026-08-17)

파일: `assets/banner.png` (2048×1152) · 생성기 `pipeline/banner.py`

캐릭터(오른쪽) + 휴지 마스코트(왼쪽) + 가운데 텍스트 3줄 구성.

```
썰푸는휴지
어 나도 그런데, 싶은 것들
심리 · 관계 · 요즘 사회  |  30초
```

유튜브 배너는 기기마다 보이는 범위가 다르다. **텍스트는 전부 안전영역
(1235×338) 안**에 두고 마스코트는 그 바깥으로 뺐다 — 모바일에서는 글자만
깔끔하게 보이고, 데스크톱·TV 에서 캐릭터가 드러난다.

| 범위 | 크기 | 무엇이 보이나 |
|---|---|---|
| 전체 (TV) | 2048×1152 | 캐릭터 전신 + 휴지 + 텍스트 |
| 데스크톱 | 2048×423 | 좌우 마스코트 + 텍스트 |
| **안전영역 (모바일)** | **1235×338** | **텍스트 3줄만** |

`banner.py` 는 세 줄 높이를 먼저 재서 안전영역 안에 수직 중앙 정렬하므로,
문구를 바꿔도 잘리지 않는다. 미리보기 두 장을 같이 뱉는다
(`codex-images/_preview-banner-desktop.png`, `_preview-banner-safe.png`).

다시 만들려면:

```bash
python3 pipeline/banner.py
```

문구는 `banner.py` 상단의 `NAME` / `TAGLINE` / `SUBLINE` 만 고치면 된다.

## 2. 채널 설명 (소개글)

유튜브 채널 설명은 **1,000자 제한**이고, 검색 결과와 채널 미리보기에는
**앞 100자 정도만** 노출된다. 핵심을 맨 앞에 둔다.

### ✅ 확정 — **적용 완료 (2026-08-17)**

```
사람 얘기를 합니다.

왜 그런지는 몰라도
"어 나도 그런데" 싶은 것들.

심리, 관계, 요즘 사회에서
다들 겪는데 아무도 설명 안 해준 것들.

30초 안에 하나씩 정리해서 올립니다.
```

대본의 음슴체 톤과 이어져 채널 정체성이 일관되게 읽힌다.

### 보류 — 검색 노출 우선안

```
매일 겪는데 이름은 몰랐던 것들을 30초로 정리합니다.
심리학 실험, 사회실험, 일상 관찰 콘텐츠를 올립니다.
```

키워드를 본문에 넣어 노출을 노리는 안. 톤이 설명체라 채널 개성이 약해져 보류.
쇼츠는 추천 알고리즘으로 돌기 때문에 채널 설명의 검색 기여도가 낮다.

## 3. 함께 설정할 것

| 항목 | 값 | 경로 |
|---|---|---|
| ~~채널 배너~~ | ✅ `assets/banner.png` 적용 완료 | 위 §1-2 참조 |
| 채널 키워드 | `심리, 사회실험, 심리실험, 관계, 자기이해, 쇼츠` | 설정 → 채널 → 기본정보 |
| 워터마크 | 아직 안 넣음. `assets/tissue.png` 를 150×150 으로 줄여 쓰면 된다 | 브랜딩 → 동영상 워터마크 |
| 링크 | 없으면 생략 | 맞춤설정 → 기본정보 |

자나스는 영상 하단에 `@자나스` 워터마크를 넣는다. 우리도 동영상 워터마크를
켜두면 캡처가 퍼질 때 채널명이 함께 노출된다.
