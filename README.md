## 제작 흐름

```
① 소재 기획   docs/topics.md 에서 다음 주제 선택
              (뉴스 기사 소재는 D형 — 오해유도 반전 구조. script-guide.md §6-3)
              제목은 docs/script-guide.md §3 규칙으로 다듬는다
② 대본 작성   GPT/Claude 프로젝트(지침=docs/script-guide.md)에 주제 입력
              → 대본 + script.json 을 함께 받음
③ 저장        work/<slug>/script.json 으로 저장
④ 이미지      work/<slug>/img/ 에 콘텐츠 이미지 넣기 (없으면 회색으로 렌더)
⑤ TTS         python3 pipeline/tts.py <slug>
              (타입캐스트가 막혔으면 python3 pipeline/tts_edge.py <slug> 를
               먼저 돌린 뒤 ⑤ 를 실행 — 무료 남성 나레이션 대체 경로)
⑥ 프레임      python3 pipeline/render.py <slug>
⑦ 조립        python3 pipeline/build.py <slug>
              → work/<slug>/<slug>.mp4
⑧ 업로드 메타  work/<slug>/upload.md 작성 (제목·설명·해시태그·고정댓글)
⑨ 업로드      docs/upload-workflow.md 순서대로 (ScaleMaker Chrome MCP)
```

**업로드 후 고정 댓글을 반드시 단다.** 100일 실험의 결론이 "댓글이 조회수를
만든다"였다. 질문형으로 달아 답글을 유도한다.

한 편 기준 ③~⑦은 명령 3줄이면 끝난다.

> **TTS 대체 경로** — 타입캐스트가 `403 UNUSUAL_ACTIVITY_DETECTED`(무료 계정 남용 감지)로
> 막히면 `pipeline/tts_edge.py` 가 Microsoft Edge TTS 로 같은 결과물을 만든다. 계정·키·결제가
> 필요 없다. 나레이션 `ko-KR-InJoonNeural`(남성), 대사 `ko-KR-HyunsuMultilingualNeural`.
> `pip3 install edge-tts` 만 있으면 된다. 타입캐스트가 풀리면 `tts/` 를 비우고 ⑤ 만 다시 돌린다.

> ⚠️ **이미지 매핑은 `tts/timing.json` 이 들고 있다.** `render.py` 는 `script.json` 이 아니라
> `timing.json` 의 `img` 를 읽는다. `script.json` 의 `img` 만 고치고 TTS 를 다시 안 돌리면
> 매핑이 반영되지 않는다(이전 편의 배치가 그대로 남는다). 나레이션은 그대로 두고 매핑만
> 바꾸려면 `timing.json` 의 `img` 를 직접 패치한 뒤 ⑥⑦만 다시 돌린다.

## 화면 규격

레퍼런스 프레임(414×738)을 실측해 **1080×1920** 으로 옮긴 값.
전부 `pipeline/layout.py` 한 파일에 모여 있다 — 디자인 수정은 여기만 건드린다.

> **이 규격은 잠겨 있다.** bystander 편 기준값이 `pipeline/layout.lock.json` 에
> 고정돼 있고, `render.py` 가 렌더 전에 대조한다. 어긋나면 렌더가 멈춘다.
> 바꾸는 절차는 `docs/layout-lock.md` 참조.

| 밴드 | 세로 위치 | 내용 |
|---|---|---|
| 상단 여백 | 0 ~ 12.7% | 검정. 쇼츠 상단 UI(검색·⋮)가 올라오는 자리 |
| 타이틀 1행 | 12.7 ~ 19.0% | **흰색** · 관찰 |
| 타이틀 2행 | 19.0 ~ 26.9% | **형광 노랑 `#FBFF56`** · 키워드 |
| 검정 간격 | 26.9 ~ 27.5% | 11px — 타이틀을 이미지에 붙였다 |
| 콘텐츠 | **27.5 ~ 71.0%** | 이미지, 좌우 꽉 참 |
| **캐릭터** | 이미지 상단에 걸침 | **초반 2초만** 노출. 폭 12.7%, 정중앙 |
| 워터마크 | **68.6%** (이미지 안쪽 하단) | `@썰푸는휴지` 반투명 · **항상 고정** |
| 자막 | **74.5%** (이미지 바로 밑) | 잘난체, 자간 -2, 10자 내외 1줄 |
| ~~프로필·채널명~~ | — | **제거됨** (`SHOW_EMBLEM = False`). 유튜브가 바로 아래 같은 정보를 띄워 중복 |
| ⛔ 데드존 | **85.5% 이하** | 쇼츠 UI(채널명·설명·진행바)가 덮는다 |

> **워터마크** — 이미지 하단 안쪽에 `@썰푸는휴지` 를 항상 넣는다. 캡처가 퍼질 때
> 채널명이 같이 나가는 역할이라 끄지 않는다. 하단 프로필+채널명과 역할이 겹쳐 보여도
> 둘 다 유지한다 — 워터마크는 **이미지에 박히는 것**이고, 하단 프로필은 화면 밖 여백에
> 있어 캡처·재업로드 시 잘려 나간다. `layout.py` 의 `WATERMARK` 를 빈 문자열로 두면 꺼진다.

> **데드존** — 유튜브 쇼츠는 화면 하단을 자체 UI 로 덮는다. `layout.py` 의
> `DEADZONE_TOP`(85.5%) 아래로는 어떤 요소도 두지 않는다. 하단 프로필·채널명은
> 91.2%/95.2% → 80.0%/82.8% 로 올려 쓰다가, 유튜브가 바로 아래에 같은 정보를
> 띄워 중복이라 아예 껐다(`SHOW_EMBLEM = False`). 켜고 싶으면 `True` 로 되돌린다.

- 타이틀 2행은 **같은 폰트 크기로 통일** — 레퍼런스처럼 한 덩어리로 읽히게
- 타이틀·자막에 검정 외곽선 → 밝은 이미지 위에서도 가독성 유지
- 폰트: 타이틀·흰바 Pretendard, **자막 잘난체(JalnanGothic)**
- 자막은 **한 문장을 10자 내외 덩어리로 쪼개 순차 노출**한다 (`pipeline/subs.py`).
  어절 경계만 자르고, 6자 이하 조각은 앞과 합친다 — 조사가 동강나지 않게.
- 자간을 줄 때는 외곽선과 본문을 **2패스로** 그린다. 한 번에 그리면 다음 글자의
  외곽선이 앞 글자 획을 덮어써 글자가 뭉개진다.
- 최종 **1.4배속** (`layout.py` 의 `SPEED`). 영상 `setpts`, 음성 `atempo` 를 같이 건다.
- 나레이션 마감은 `pipeline/audio.py` 가 맡는다 — 폰 스피커 EQ → 컴프 → **-14 LUFS**(유튜브 기준).
  이걸 빼면 -25 LUFS 로 나가서 피드에서 우리 것만 작게 들린다.
  (같은 파일의 `PACING` 은 문장 역할별 완급 실험. 2026-08-19 에 껐다.)

### 애니메이션

`render.py` 는 이미지 자리를 **투명하게 비운 오버레이**만 만들고, `build.py` 가
프레임마다 이미지를 움직여 합성한 뒤 ffmpeg 표준입력으로 흘려보낸다(디스크에 안 쓴다).

| 종류 | 동작 | 설정 |
|---|---|---|
| 등장 | 첫 이미지가 검정에서 밝아지며 살짝 축소되어 자리잡음 | `INTRO_SEC` 0.45초 |
| 설명 | 구간 내내 아주 천천히 확대/축소. 구간마다 방향 교대 | `KEN_ZOOM` 0.09 |
| 교체 | 다음 이미지가 오른쪽에서 밀고 들어옴 | `SLIDE_SEC` 0.32초 |

### 무음 제거

`tts.py` 가 문장마다 앞뒤 무음을 **완전히** 잘라내고 내부 정적은 0.05초로 압축한다
(임계 -38dB). 문장 사이 간격(`--gap`)은 기본 0.03초.

### 목소리와 톤

한 톤으로 쭉 읽으면 기계처럼 들린다. 문장 성격에 따라 자동으로 톤을 바꾼다.

| 문장 끝 | emotion | intensity |
|---|---|---|
| `?` 질문 | toneup | 1.5 |
| `!` 강조 | toneup | 1.8 |
| `임.` `것.` `뿐.` 여운 | tonedown | 1.3 |
| 그 외 | normal | 1.2 |

`script.json` 의 각 line 은 문자열 대신 객체로 쓸 수 있다 —
`{"text":..., "dialogue": true, "img": 8}`  ← 대사는 자바바 목소리로 자동 전환

`"dialogue": true` 를 주면 **대사 처리**된다 — 화자가 자바바로 바뀌고, 톤이 강하게
잡히고, 앞뒤에 숨이 붙는다. 대사는 예외 없이 이 화자를 쓴다.
`img` 는 그 문장에 붙일 이미지 번호(1-based).

## 대본 규칙

전문은 `docs/script-guide.md`. 핵심만:

- **음슴체**, 존댓말·이모지·특수문자 금지
- 분량 **25초~50초** (최종 1.4배속 기준) — 문장 13~23개
- 첫 문장은 제목 그대로 읽기
- 제목은 '설명'이 아니라 **'발견'** — 결론·개념어를 제목에 넣지 않는다
- 본문 **중반에 명칭 공개** ("이걸 인지 자원 고갈이라고 하는데.")
- 마지막은 감탄·여운으로 마무리
- 금지: AI식 해설("심리학에 따르면"), 뉴스 헤드라인식 자극, 정보 나열
- **중복 주제 3주 내 재사용 금지**

`lines` 배열은 **한 문장 = 한 원소**. 각 원소가 TTS 1구간이 되고,
렌더 단계에서 다시 10자 내외 자막 덩어리로 쪼개진다.
한 원소는 **한 호흡에 읽히는 길이**로 — 25자 안팎이 적당하다.

각 원소는 문자열 대신 객체로 써서 화자·톤·이미지를 지정할 수 있다:
`{"text":..., "dialogue": true, "img": 8}`  ← 대사는 자바바 목소리로 자동 전환

## 설정

```
.env
  TYPECAST_API_KEY=...      # 타입캐스트 API 키
  TYPECAST_VOICE=tc_...     # voice_id (미설정 시 효은 기본값)
```

`assets/character.png` — 채널 캐릭터(배경 투명). 초반 2초 동안 흰 바 위에 뜬다.
`assets/profile.png` — 하단 채널 프로필 이미지(정사각). 없으면 빈 원으로 렌더.
`assets/tissue.png` — 두루마리 휴지 마스코트(배경 투명). 배너·워터마크용.
`assets/banner.png` — 채널 배너. `python3 pipeline/banner.py` 로 다시 만든다.
BGM 은 쓰지 않는다 — 나레이션만으로 제작한다.

## 운영 원칙 (100일 실험에서 가져온 것)

1. **댓글이 달릴 수밖에 없는 주제를 고른다.** 터진 영상의 공통점은 좋아요가 아니라 댓글이었다 — 댓글을 읽고 쓰는 동안 영상이 반복 재생되어 시청 지속률 95%+가 나온다.
2. **시기를 타지 않는 주제만 한다.** 화제성 소재는 하루 만에 멈추고, 시기 무관 주제는 몇 주 뒤 역주행한다.
3. **초반 1만 회를 못 넘기면 그대로 묻힌다.** 10만이 붙어야 100만 가능성이 생긴다.
4. **성과는 6주 뒤부터.** 레퍼런스도 25일차까지 무성과였다.
