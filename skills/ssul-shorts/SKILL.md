## 대본 형식 (핵심)

- **음슴체**, 존댓말·이모지 금지. `docs/script-guide.md` §2
- **시청자 호칭은 `님들`** (`니들` 금지, 2026-09-05). 질문 마감·고정 댓글 포함
- **연결어구를 반드시 넣는다** — 문장이 따로 놀면 안 되고 누군가에게 설명하듯 이어져야 한다
  - `~했더니 / ~봤더니 / ~앉혀놨더니` 로 원인과 결과를 한 호흡에 묶는다
  - `근데 / 그래서 / 그러니까 / 여기서` 로 문단을 넘긴다
  - `~고` 로 끝내고 다음 문장이 받는다
- **숫자는 한글이 아니라 숫자로 쓴다** — `구십 명`(X) → `90명`(O), `삼분의 일`(X) → `3분의 1`(O)
  - 자막 가독성 때문이고, 타입캐스트는 숫자를 정상적으로 읽는다
- **영문 약자는 한글 발음으로 쓴다** — TTS 가 알파벳을 그대로 읽는다.
  `콜라 L`(X) → `콜라 라지`(O), `R`(X) → `레귤러`(O)
- **커뮤니티 글이 소재면 본문에서 벗어나지 않는다** — 제목만 보고 재구성하지 말고
  본문을 열어 읽는다. **욕설·비하만 걷어내고 내용·순서·수치는 그대로.**
  - 개드립 본문은 **대부분 캡처 이미지**라 정적 파싱이 빈 문자열을 돌려준다.
    짧은 글은 `chrome_screenshot` + `selector: '.xe_content'` 한 장이면 다 읽힌다
  - 수만 px 짜리 긴 카톡 스레드는 통짜로 찍으면 축소돼 안 읽힌다.
    `img` 에 번호를 박아 **한 장씩** 찍는다 —
    `[...document.querySelectorAll('.xe_content img')].forEach((im,i)=>im.setAttribute('data-n',i))`
- **원글이 단정한 것을 그대로 단정하지 않는다.** 본문 충실은 *내용*을 살리라는 뜻이지
  *확신의 세기*까지 베끼라는 뜻이 아니다. 근거가 댓글·추측이면 그 층위를 밝힌다
  (예: "떡 넣는 이유" 는 업계 설명이 아니라 댓글 해석이라 제목을 관찰형으로 바꿨다)
- **인용된 통계는 원 보도를 찾아 연도·표본·대상을 확인한다.** 숫자가 맞아도 제목이
  과장이 되는 경우가 있다 (예: "요즘 2030 퇴사 이유" → 실제로는 2020년·전 연령
  조사라 제목·대본에서 연령·시점 표현을 뺐다)
- **화자는 우리다.** `커뮤니티에 이런 글이 올라왔음` 같은 중계 화법 금지. 그 글을
  아는 사람이 **직접 설명하듯** 말한다. 남의 계산은 `~라고 치고`, `~해보자` 로 같이 따라간다.
  확정 안 된 수치만 `계산해보면`, `의견이 갈림` 으로 여지를 남긴다.
  상세는 `docs/script-guide.md` §4-2
- 제목에 결론·개념어 금지. 명칭은 **본문 중반에 발견하듯** 공개 (§3, §6)

## 흰 바 — 제목 + 파란 댓글 수 (2026-08-30 추가, 표준)

타이틀 밑·이미지 상단에 **흰 배경 + 검정 한 줄 제목 + 파란 `(댓글수)`** 바가
**첫 문장(타이틀 나레이션)을 읽는 동안만** 떴다 사라진다. 새 편은 항상 넣는다:

```json
"style": {
  "sub_box": true,
  "bar": "나라 돈 2,792억 지켜낸 공무원이 받은 포상금",
  "bar_count": 123
}
```

- `bar` = 흰 바 문구(hook 전문 느낌으로, `ㄷㄷ` 류 꼬리는 뺀다)
- `bar_count` = **원글의 실제 댓글 수만** 적는다 (파란색 `(000)` 으로 붙음)
- 바가 있는 동안 워터마크는 바 아래로 자동 이동. 키가 없으면 화면 불변
- 상수: `BAR_H` 0.055 · `BAR_CNT` 파랑 — `layout.py`, 57개 상수로 잠금

**상단 캐릭터는 껐다** (2026-08-30, `CHAR_SEC = 0`). 되살리려면 2.0.

## 자막 — 숫자와 단위는 가르지 않는다 (2026-08-30)

`pipeline/subs.py` 가 자막을 10자 내외로 쪼갤 때, 숫자(+억/만/천 등)로 끝나는 어절
뒤에 단위 어절(원·년·명·개·주·퍼센트 …)이 오면 **한 덩어리로 붙인다.**
`2,792억 / 원을` 처럼 갈라지는 걸 막는 규칙이라 대본에서 신경 쓸 필요는 없지만,
새 단위가 갈라지면 `UNIT_HEAD`/`_NUM_TAIL` 에 추가한다.

## 강조 자막 — 을지로체 + 연두/노랑 (2026-08-28 추가)

한 문장에서 **핵심 한 덩어리만** 배달의민족 을지로체로 튄다. 통째로 색칠하면
강조가 아니라 그냥 다른 색 자막이 된다.

```json
{ "text": "아내는 혼자 세월을 역주행했다고 함.", "em": ["세월을 역주행"] }
{ "text": "아내 나이가 39살인데", "em": ["39살"], "em_color": "yellow" }
```

| 항목 | 값 |
|---|---|
| 폰트 | `BMEULJIROTTF.ttf` · 크기 기준 자막의 **1.14배**(`EM_SIZE_R`) |
| 연두(기본) | `#A8FF60` |
| 노랑 | `#FBFF56` — `"em_color": "yellow"` |

- 폰트가 달라도 **베이스라인을 맞춰** 그린다
- **강조어는 자막 덩어리 경계에 자주 걸린다**("세월을" / "역주행"). 구간을
  문장 전체에서 잡아 덩어리별로 잘라 넣는다 — 덩어리 안에서만 찾으면 조용히 빠진다
- 강조가 없는 줄은 기존 경로 그대로라 잠금 화면이 안 바뀐다

edge-tts(`tts_edge.py`)는 **타입캐스트가 막혔을 때만 쓰는 임시 경로**다. 목소리가 달라지므로
채널 톤이 튄다. 크레딧이 풀리면 `rm work/<slug>/tts/*` 후 ④부터 다시 돌려 민욱으로 되돌린다.

## 업로드

**기본 예약 슬롯은 오전 7시(KST)** — 하루 1편씩 날짜만 밀어 잡는다 (2026-08-28 확정).
같은 날 여러 편이면 13:00 / 17:00 / 20:00 과 섞는다. 시간은 **드롭다운에서 "오전 7:00"**
을 고르고(값을 써넣으면 0시로 저장), 날짜는 **월 헤더 기준**으로 찾는다.
**하루 업로드 한도**가 있어 한 세션에 여러 편이면 중간에 막힐 수 있다.

`docs/upload-workflow.md` 가 단일 출처. 반드시 지킬 것:

- 계정은 **`.env`의 `YT_ACCOUNT` 계정 / 썰푸는휴지**. `youtube.com/account` 에서만 확인하고
  **`youtube.com/logout` 은 절대 열지 않는다**
- 제목·설명은 `execCommand('insertText')` 로만 넣는다(키보드 시뮬레이션은 제목 칸에
  설명이 통째로 붙는 사고를 낸다). 단 **`box.focus()` 만으로는 조용히 무시된다** —
  반드시 **좌표를 클릭**해 실제 포커스를 준 뒤에 넣는다
- 라디오 버튼은 좌표가 아니라 `el.click()`
- **예약 날짜를 `today + N` 으로 세지 않는다.** 달력은 월별 그리드라 그 달 마지막 주
  뒤에 빈 칸이 붙어, 오프셋으로 세면 기본값(내일)으로 잡힌다. 실제로 한 편이 엉뚱한
  날짜로 예약돼 다른 편과 겹쳤다. **월 헤더 기준으로 "몇 월 며칠"을 직접 찾는다.**
  날짜·시간 항목은 shadow DOM 안이라 `shadowRoot` 까지 훑어야 잡힌다
- 달력은 연 직후 칸이 비어 있다. **스크린샷을 한 번 찍어 리페인트를 강제**해야 렌더된다
- 잘못 잡힌 예약은 **영상 편집 화면(`/video/<ID>/edit`)의 공개 상태 카드**에서 고칠 수
  있다(2026-08-25 확인). 지우고 다시 올릴 필요 없다 — 영상 **파일**만 교체 불가
- **게시 직전에 제목·설명·공개범위를 사용자에게 보여주고 확인받는다.** 되돌리기 어려운 공개 행동이다
- 게시 후 **고정 댓글**을 반드시 단다(질문형). 채널 100일 실험의 결론이 "댓글이 조회수를 만든다"
  - 쇼츠는 댓글 패널을 연 뒤 `#simplebox-placeholder` 클릭 → `#contenteditable-root` 에 입력
    → `#submit-button`. **패널이 자주 재렌더되므로 클릭·입력·등록을 한 스크립트에서 끝낸다**
  - 고정 처리는 전화번호 인증(일회성, 사람이 직접)이 먼저다
- 업로드 후 `docs/upload-workflow.md` 기록표에 링크를 남긴다

## 화면·소리 규격 (2026-08-22 확정)

`layout.py` 원본과 `layout.lock.json` 은 건드리지 않는다. 편별 차이는 `script.json` 의
`"style"` 블록으로만 준다 — 그래야 락이 안 깨지고 다른 편에 번지지 않는다.

```json
"style": { "sub_box": true }
```

| 키 | 뜻 |
|---|---|
| ~~`speed`~~ | **적지 않는다.** `build.py` 는 이 키를 읽지도 않는다. 배속은 `layout.py` 의 `SPEED` = **1.3 고정**이다 |
| `sub_box` | 자막을 **이미지 안쪽 검은 사각 박스 + 흰 글씨**로. 페더 0, 모서리 안 굴림 |
| `motion` | 켄번스 5종 + 전환 4종 순환. **기본은 끈다** — 써봤더니 산만했다. 슬라이드만 쓴다 |

- `sub_box` 를 켜면 워터마크가 자막 박스와 겹치므로 **자동으로 이미지 상단으로 올라간다**
- **시작 "띵~"** — `assets/chime.wav` 가 있으면 `build.py` 가 자동으로 맨 앞에 얹는다.
  880Hz + 배음 3개를 코드로 합성한 파일이라 라이선스 문제가 없다. 끄려면 `--no-chime`.
  배속을 건 **뒤에** 원속도로 얹어야 한다 — 같이 배속되면 종소리가 딸깍 소리가 된다

## 여러 편을 한 번에 돌릴 때

10편이면 이미지가 90~100장이다. 워커를 나눠 돌리는데 여기서 두 번 넘어졌다.

- **백그라운드 워커는 부모 셸과 함께 죽는다.** `for w in 0 1 2 3; do ./run.sh $w & done`
  로 띄우면 그 명령이 끝날 때 워커도 죽어 **각자 1장만 만들고 멈춘다.**
  `nohup ./all.sh > all.out 2>&1 < /dev/null &` 로 떼어낸다
- **macOS 에는 `setsid` 가 없다.** `nohup setsid ...` 는 조용히 아무것도 실행하지 않는다.
  띄운 뒤 몇 초 있다 `pgrep -fl 'run\.sh'` 로 살아 있는지 반드시 확인한다
- **진행 확인은 편별로.** 전체 장수만 세면 어느 편이 덜 찼는지 안 보인다
- **순서는 TTS 부터.** TTS 10편은 몇 분이면 끝나고 이미지와 자원이 안 겹친다.
  먼저 돌려두면 이미지가 채워지는 편부터 바로 ⑤⑥ 으로 넘어갈 수 있다
- codex 이미지 생성은 **다른 프로젝트의 codex 작업과 경합한다.** 장당 30~60초가
  3~4분까지 늘어난다. 배치 전에 `pgrep -f gen.sh` 로 확인한다
- 배치일 때만 `build.py --no-open`. 다 끝나면 **영상 창이 아니라 폴더를 연다**

상세는 `prd.md` §8-3.

## 업로드 후 정리

한 편이 ~30MB 다. **업로드·예약이 끝나면 미디어를 지우고 기록만 남긴다.**

```bash
rm -rf work/<slug>/{img,tts,frames,tmp} work/<slug>/<slug>.mp4
```

**`script.json` 과 `upload.md` 는 절대 지우지 않는다** — 대본·메타·근거표가 들어 있고,
이것만 있으면 전 과정을 재현할 수 있다. 구버전 이미지 폴더(`img_anime` 등)도 함께 정리.
상세는 `prd.md` §8-2.
